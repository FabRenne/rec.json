# Cours débutant : les Fragments avec Jetpack Compose

- **`Cours_Fragments_Jetpack_Compose.pdf`** : le cours (28 pages, A4), avec exemples de code et captures d'écran.
- `captures/` : les captures d'écran des exemples (PNG).
- `src/` : sources du cours (`cours.html`, `maquettes.html`) et script de génération.

Régénérer le PDF : `cd src && node build.js` (nécessite Playwright + Chromium).
