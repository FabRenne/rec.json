# Cours : les thèmes en Jetpack Compose (débutants)

- `cours-themes-jetpack-compose.pdf` — le cours (23 pages, 10 chapitres, exercices, mémo).
- `captures/` — les 17 captures d'écran utilisées dans le cours (PNG haute résolution).
- `code-android/` — le code de l'application exemple « Mon Jardin » (Color.kt, Type.kt, Shape.kt,
  CouleursEtendues.kt, Theme.kt, EcranJardin.kt, MainActivity.kt) à copier dans un projet Android Studio.
- `generateur-captures/` — le projet Compose (Kotlin/JVM) qui génère les captures (`gradle run`)
  et le script Python qui génère le PDF (`python3 generer_pdf.py .. ../cours-themes-jetpack-compose.pdf`).
